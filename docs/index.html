What it does

Takes a page you paste, keeps it with its date, and searches it offline. A rule that matches nothing says so and says the rule may be wrong or the page may have changed — the app cannot tell which.

What it refuses

It does not crawl. There is no network code at all, so a page can only arrive because you brought it — and every rule shows “not run since …” in words, with the age.
