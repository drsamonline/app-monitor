Monitor

The pages you chose to keep, with the date you kept them, searchable offline. It does not crawl the web.

Open Monitor
Status Built and working offline: a page is archived only when you paste it, with the date it was saved; a small selector grammar checked when the rule is saved, so a rule that does not parse is never run; rows from a run; and a search over everything kept, each hit showing its date.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: crawling or fetching. There is no network code in the app at all, so a page can only arrive because you pasted it — and every rule shows “not run since …” with the age in words rather than pretending to be live.

What it does

  • Archives a page you paste, with its address, its title and the date you kept it.
  • Runs a saved rule against a pasted page and shows the rows it matched.
  • Searches everything you kept, offline, and shows each hit with the date it was saved.
  • Tells you how long ago each rule last ran, in words.

What it will not do

  • Crawl the web. No fetch, no crawler, no url queue.
  • Run a rule it did not understand. Selectors are checked when saved, with the value shown.
  • Show an empty table for a scrape that matched nothing. It says so, and says that is not the same as “no results”.
  • Lose the rules with a broken table. They are stored separately.
  • Replace an unreadable archive with an empty one.

When things go wrong

CaseWhat happens
Bad inputA selector or address that does not parse is refused when saved, with the reason. A rule with no name is refused.
No networkNothing changes; saved pages and dates still open, and every rule shows “not run since …” with the age in words.
Storage full or unavailableNew rows are not written; the app says they were dropped and gives the date range of what was kept.
Corrupt saved stateReported and offered for export; the rules are read and shown, because they are stored separately.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
