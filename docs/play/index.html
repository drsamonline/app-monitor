Save a page you kept

Paste the page's text (or its HTML). It is archived with today's date, and it is the only way a page gets in here.

A rule

A small selector grammar: div, .class, h2.headline, #id, a[href=/story]. It is checked when you save it, so a rule that does not parse is never run against your page.

    Rows from the last run

    A rule that matches nothing says so, and says the rule may be wrong or the page may have changed — the app cannot tell which.
